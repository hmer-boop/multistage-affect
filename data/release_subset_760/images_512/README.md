# Low-Resolution Artmajeur Images

Important: the review subset contains 760 labeled items. This image folder contains only the Artmajeur-linked images for which the author has received a platform reply supporting non-commercial academic use of low-resolution images. The smaller image count should not be interpreted as the size of the study dataset.

This folder contains the low-resolution 512 px image files for Artmajeur-linked items in the 760-item review subset.

## Files

- `artmajeur/`: included 512 px image files.
- `artmajeur_images_manifest.csv`: item-level manifest linking each included file to its item ID, title fields, and source/provenance URL.
- `00_IMAGE_RELEASE_NOTICE.md`: short reviewer-facing explanation of why only the permitted subset of image files is included.

## Scope and Use

These images are included after the author received a written platform reply from the Artmajeur team allowing general non-commercial academic, research, and educational use of low-resolution images available on Artmajeur, with proper attribution to the artist and Artmajeur.

Copyright remains with the individual artists. This folder should not be treated as a blanket license for commercial use, high-resolution reuse, or redistribution outside the stated academic context. For higher-resolution images or broader permissions, contact the relevant artist through the original platform page.

Images from source sites whose replies remain unresolved are not included here. Those items remain link-only in the provenance tables under `../provenance/`.

The provenance tables are intentionally left unchanged: they keep the original source links for review, attribution, and manual lookup, while this folder separately stores the low-resolution Artmajeur files that are released with the repository.
