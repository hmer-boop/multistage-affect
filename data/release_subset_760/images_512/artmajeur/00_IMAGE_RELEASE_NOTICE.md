# Image Release Notice

These are the low-resolution 512 px image files for Artmajeur-linked items in the 760-item review subset.

The full benchmark contains 3,210 artwork items. Because the manuscript is still under review, this repository currently releases a 760-item subset with traceable labels, metadata, and source/provenance information. After acceptance, the authors plan to release traceable provenance information for the full 3,210-item benchmark, subject to copyright, source-site terms, and publication policy.

This folder contains only the image files for the Artmajeur-linked portion of the 760-item subset because this is the source for which the author has received a platform reply supporting non-commercial academic use of low-resolution images with proper attribution.

The remaining items are still included in the labels, metadata, and provenance tables, but their image files are not redistributed here while source-site permission replies remain unresolved.

See `../README.md` and `../00_IMAGE_RELEASE_NOTICE.md` for the full image availability statement.
