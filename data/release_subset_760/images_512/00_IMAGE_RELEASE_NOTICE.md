# Image Release Notice

The full benchmark contains 3,210 artwork items.

Because the manuscript is still under review, this repository currently releases a 760-item review subset with traceable labels, metadata, and source/provenance information. After acceptance, the authors plan to release traceable provenance information for the full 3,210-item benchmark, subject to copyright, source-site terms, and publication policy.

This folder does not contain image files for all 760 released subset items. It contains only the low-resolution 512 px files for Artmajeur-linked items for which the author has received a platform reply supporting non-commercial academic, research, publication, and teaching use with proper attribution to the artist and Artmajeur.

The remaining labeled items are still part of the 760-item review subset. Their labels, metadata, and source/provenance links are provided in:

- `../labels/gold_label.json`
- `../metadata/items_public.jsonl`
- `../provenance/image_provenance_review.csv`
- `../provenance/image_provenance_review.xlsx`
- `../provenance/image_sources_manifest.csv`

Images from other source sites are not included as files because source-site permission replies remain unresolved. For those items, reviewers can inspect the source URL and title fields in the provenance tables. Researchers who need additional images should obtain them from the original source websites and follow the applicable website and artist terms.

Copyright for each artwork remains with the individual artist. These files are provided only for scholarly review, reproducibility checking, and non-commercial academic use; they are not a blanket license for commercial use, high-resolution reuse, or redistribution outside that context.
