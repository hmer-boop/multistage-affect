# Image Release Notice

These are the image files for ArtMajeur-sourced items in the 760-item review subset.

The full benchmark contains 3,210 artwork items. Because the manuscript is still under review, this repository currently releases a 760-item subset with traceable labels, metadata, and source/provenance information. After acceptance, the authors plan to release traceable provenance information for the full 3,210-item benchmark, subject to copyright, source-site terms, and publication policy.

This folder contains the image files for the ArtMajeur-sourced portion of the 760-item subset because these samples have received explicit permission from the rights holder/source platform and can be made available with the dataset for non-commercial academic use with proper attribution.

The remaining items are still included in the labels, metadata, and provenance tables, but their image files are not redistributed here under the repository's conservative peer-review-stage image-file release policy. This should not be read as reducing the 760-item subset or as indicating that the remaining items lack provenance.

See `../README.md` and `../00_IMAGE_RELEASE_NOTICE.md` for the full image availability statement.
