# ArtMajeur Image Files

Important: the review subset contains 760 labeled items. This image folder contains the ArtMajeur-sourced images for which the author has received explicit permission from the rights holder/source platform. These samples can be made available with the dataset for non-commercial academic use with proper attribution. The image-file count in this folder should not be interpreted as the size of the study dataset or as excluding the remaining labeled items.

This folder contains the image files for ArtMajeur-sourced items in the 760-item review subset.

## Files

- `artmajeur/`: included ArtMajeur image files.
- `artmajeur_images_manifest.csv`: item-level manifest linking each included file to its item ID, title fields, and source/provenance URL.
- `00_IMAGE_RELEASE_NOTICE.md`: short reviewer-facing explanation of why only the permitted subset of image files is included.

## Scope and Use

These images are included after the author received explicit permission from the ArtMajeur rights holder/source platform, allowing the ArtMajeur-sourced samples to be made available with the dataset for general non-commercial academic, research, and educational use with proper attribution to the artist and ArtMajeur.

This folder should not be treated as a blanket license for commercial use or redistribution outside the stated academic context. For broader permissions, contact the relevant rights holder through the original platform page.

Other artwork images are not included here as files under the repository's conservative peer-review-stage redistribution policy. Those items remain traceable through the provenance tables under `../provenance/`.

The provenance tables are intentionally left unchanged: they keep the original source links for review, attribution, and manual lookup, while this folder separately stores the ArtMajeur files that are released with the repository.
