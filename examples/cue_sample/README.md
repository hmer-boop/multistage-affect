# Cue Sample 120

This folder contains representative cue examples for 120 selected items.

The files are intended for review and inspection of the three-stage cue format. They are not the complete cue set used in the full experiments.

## Files

- `selected_ids.json`: item IDs in this cue sample.
- `metadata/items_public.jsonl`: public metadata for the sample.
- `labels/gold_label.json`: gold labels for the sample.
- `cues/stage1_cues.json`: Stage 1 cue examples.
- `cues/stage2_cues.json`: Stage 2 cue examples.
- `cues/stage3_context_cues.json`: Stage 3 context cue examples.
- `reports/sample_stratum_distribution.csv`: label distribution of this cue sample.
